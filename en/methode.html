Method

How the instruments are built

Every instrument follows the same working method, without a star schema or data warehouse. There is no central database: each page fetches the figures from the source or carries them itself, and sets them side by side in your browser on shared keys.

The structure

Each source keeps its own level. An energy label belongs to a building, a Wmo figure to a district, an Iv3 amount to a municipality. A figure is not spread over a lower level. What exists only per municipality stays per municipality, and the page says so.

Shared keys connect the sources. The municipality code runs through everything. District and neighbourhood codes and BAG IDs connect where the source knows them. This creates four families: per object, per neighbourhood and district, per municipality with a flow of people, and per municipality with money.

The same key is not enough. Two figures at the same level need not match each other. Wmo expenditure per type divided by clients per type gives nonsense in many municipalities, because the registers differ. That division is therefore not shown.

The source is examined too. A jump in a series is first read as a possible change in the register, not as a change in the world. What does not exist or cannot be said is stated.

An outcome can be traced. Label C gives the reasoning per building. Construction pipeline links to the official announcement. Wmo by district shows the rules that applied in that year.

The data model as a way in. Anyone who works with the Municipal Data Model (GGM, Gemeentelijk Gegevensmodel) can also start from the model: per entity which instruments fill it with open data, which indicators rely on it and what only the municipality's own register knows. The data model as a way in →

Local knowledge stays local. Your own list is read in your browser. Only queries to open sources go outside, and a list about residents does not belong here.

What this working method does not solve

Many figures arrive already aggregated: no instrument can look below the level of the source. Reference dates differ per source and district classifications change. The instruments are connected where the data support it, not everywhere. Internal sources ask for more than this: history, authorisations, personal data and the configuration of the source systems fall outside it.
